# Longitudinal Data Analysis Manual

This repository is a practical reference for BIOS767: Longitudinal Data Analysis, based primarily on the Spring 2026 course materials. It contains executable R analysis chapters, accompanying mathematical writeups, and concise references for interpretation and diagnostics. Read the manual on the [deployed page](https://wenbinwu2001.github.io/oh-my-qualify-application/).

## Structure

- `analysis-in-r/`: runnable R analysis chapters
- `math-writeups/`: mathematical formulations, assumptions, estimation, and inference
- `references/`: diagnostics, interpretation, and package references
- `_common.R`: shared R setup and helpers
- `_quarto.yml`: Quarto website configuration

[`REPRODUCIBILITY-PROMPT.md`](REPRODUCIBILITY-PROMPT.md) can guide an AI agent in creating a similar site; provide links or paths to the course slides, homework and code solutions, supplementary notes, previous exams with datasets/codebooks, and the intended repository and deployment URL.
