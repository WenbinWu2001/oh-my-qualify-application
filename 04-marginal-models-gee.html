4. Marginal models and generalized estimating equations

1. Aim

GEE estimates a population-averaged regression parameter \(\beta\) from a correctly specified marginal mean while treating within-cluster association as nuisance. The sandwich covariance gives asymptotically valid inference under working-correlation misspecification when independent clusters are sufficiently numerous and the observation process satisfies the estimating-equation assumptions.

2. Model specification

Let \[ g(\mu_{ij})=x_{ij}^{\mathsf T}\beta, \qquad \operatorname{Var}(Y_i)=V_i=\phi A_i^{1/2}R_i(\alpha)A_i^{1/2}. \] GEE solves \[ U(\beta)=\sum_{i=1}^m D_i^{\mathsf T}V_i^{-1}(Y_i-\mu_i)=0, \qquad D_i=\frac{\partial\mu_i}{\partial\beta^{\mathsf T}}. \] The model-based covariance is \(B^{-1}\); the sandwich covariance is \(B^{-1}MB^{-1}\), with \(B=\sum D_i^{\mathsf T}V_i^{-1}D_i\) and \(M=\sum D_i^{\mathsf T}V_i^{-1}r_ir_i^{\mathsf T}V_i^{-1}D_i\).

3. R packages/functions

geepack::geeglm() fits GEE with independence, exchangeable, AR(1), and unstructured working correlations; geepack::QIC() compares mean/correlation specifications; the internal geese object exposes robust and naive covariance and the estimated scale. gee::gee() is a useful alternative when SAS-like naive/robust output is desired.

Time-varying covariate decomposition

Separating a covariate into subject mean and within-subject deviation avoids conflating between- and within-subject associations. Here lagged weight is used only to demonstrate the parameterization; because it is an endogenous response history, causal interpretation requires transition-model assumptions.

dietox_tv <- dietox |>
  group_by(Pig) |>
  mutate(lag_weight = lag(Weight), mean_lag_weight = mean(lag_weight, na.rm = TRUE),
         dev_lag_weight = lag_weight - mean_lag_weight) |>
  ungroup() |>
  filter(!is.na(lag_weight))

gee_within_between <- geepack::geeglm(
  Weight ~ Time + Cu + mean_lag_weight + dev_lag_weight,
  id = Pig, waves = Time, data = dietox_tv,
  family = gaussian, corstr = "exchangeable"
)

P value adjustment: holm method for 3 tests

Time is the population-average weekly mean change in the reference feed group; Time:Cu terms are population-average differences in slopes. alpha parameterizes the chosen working correlation and is not ordinarily a scientific estimand in GEE1. For Gaussian data, \(\phi\) estimates residual scale; for binomial/Poisson responses the canonical scale is often fixed at one, although software can estimate a scale depending on options. Robust SEs come from vbeta; model-based SEs from vbeta.naiv are valid only under the working covariance model.

For nonidentity links, GEE and GLMM coefficients differ. With a logistic random-intercept GLMM, \[ \beta_{PA}\approx \frac{\beta_{SS}}{\sqrt{1+c^2\sigma_b^2}}, \qquad c=\frac{16\sqrt3}{15\pi}\approx0.588, \] so population-averaged log-odds effects are typically attenuated toward zero. Under a probit link the corresponding factor is \((1+z_{ij}^{\mathsf T}Dz_{ij})^{-1/2}\); under the identity link the coefficients coincide.

8. Caveats

  • GEE coefficients are population-averaged; GLMM coefficients are subject-specific conditional on random effects. Equality generally fails for nonidentity links.
  • Sandwich validity is asymptotic in the number of independent clusters; small-cluster corrections are not the default in geeglm().
  • Ordinary GEE is generally valid under MCAR, not arbitrary MAR dropout. Use weighted GEE or another valid missing-data method when observation depends on observed history.
  • geeglm() requires rows ordered by cluster and, for AR(1), correctly ordered waves.
  • Time-varying covariates can be external or endogenous; coefficients for endogenous covariates generally need a conditional/transition interpretation, and naive GEE can be biased when the covariate process depends on prior outcomes.
  • QIC is not AIC: it is based on quasi-likelihood and must be interpreted within comparable GEE specifications.
  • In geepack, vbeta is robust and vbeta.naiv is model-based. SAS/other R packages may label these empirical and model-based/naive; verify which covariance a printed table uses.
  • Scale estimation defaults differ across geepack, gee, and SAS PROC GENMOD/PROC GEE; set and report the rule explicitly.
  • Source-backed: estimating equations, sandwich inference, working correlations, QIC, scale, and PA interpretation follow the notes. Standard-practice addition: direct extraction helpers and emmeans::emtrends() are idiomatic R replacements for SAS contrasts.
